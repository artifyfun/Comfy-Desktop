# AI 画布功能全景（用户指南）

> 更新：2026-09-15 ｜ 适用版本：artifylab-v2（v1.3.0-49+）
> 画布入口：顶导航「画布」或 ComfyUI 界面左侧「AI 工作台」

## 一句话说清这个画布

**AI 在画布上替你干活，你随时看得见、改得了、退得回。**
它不是绘图工具，也不是纯节点编辑器——是「你说需求，AI 搭工作流并执行；每一步可拍板、可干预、可回滚」的创作面。

## 核心能力地图

### 1. 对话驱动（右侧工作台 / 画布内嵌侧栏）

| 你说 | AI 做 |
|---|---|
| 「把这几个模板搭成工作流」 | 自动铺节点+连线+横向布局（确认卡→执行） |
| 「先给我几个方案让我选」 | 弹**计划拍板卡**：步骤树 + 2~4 个方向选项，点选后继续 |
| 「用小美的风格生成」 | 查**创作资产库**，自动挂载参考图+seed+参数 |
| 「执行完成后告诉我文件名」 | 执行 → **自检产物** → 汇报（失败会说明并重试一次） |
| 「把这次的做法存成模板」 | 固化为模板（同名自动版本化） |
| 「把 xx 模板退回上一版」 | 查询/回滚版本历史 |

### 2. 画布直接操作

| 操作 | 入口 |
|---|---|
| 单节点运行 | 节点 ▶ 按钮 / 悬浮工具条 ▶ |
| **从此重跑下游** | 节点右键或悬浮工具条 ⟳「从此节点重跑下游」——改完一步，下游自动重跑 |
| 批量运行 | 框选多个 → 浮动操作栏 ▶ |
| 对齐/分布 | 浮动操作栏 / 右键菜单（含智能对齐线） |
| 连线风格 | 底栏 🖊 图标：直角线 ⟷ 贝塞尔曲线（持久化） |
| AI 快照回滚 | AI 操作前自动快照；右上角快照面板一键恢复 |
| 缩放 | 滚轮（持久化，刷新不丢）/ 底栏滑块 / ⌖ 复位 / ⛶ 适配全部 |
| 平移 | 空格+拖 / 中键拖 |

### 3. 审批与安全

- **审批分级**：读类免审；写类按模式；执行类（提交 ComfyUI / 固化模板）必弹卡
- **总是允许**：审批卡勾选「本会话内总是允许此工具」→ 本会话该工具直通（跨会话失效；每会话首次执行仍确认）
- **AI 快照**：AI 改画布前自动保存，任何 AI 操作可一键恢复
- **参数自检**：生成后自动核对产物；异常会说明差异并重试一次（不无限烧预算）

### 4. 创作资产（角色/风格一致性）

- 侧栏「创作资产库」：查看/新建/编辑/删除资产（kind + 参考图组 + seed + 参数）
- 对话创建：「把这张图存为角色资产叫小美」
- 使用：执行模板时传资产名 → 参考图自动落槽、seed 自动填
- 跨会话全局可用

### 5. 模板与版本

- 固化：对话「存成模板」或画布执行后按 prompt_id 固化
- 版本化：同名固化 = 新版本（不攒重复模板）
- 版本历史：对话查询/回滚，或模板详情面板

## 常用对话示例

```
把模板库里的 3 个模板铺到画布搭成工作流
→ [计划卡] 选方向 → [确认卡] 执行 → 节点落布(自动布局) + 自动快照

先查一下资产库有什么，然后用「小美」做参考生成 3 张不同场景的图
→ wb_assets 查询 → 逐张执行(资产自动挂载) → 自检产物 → 汇报

第二个节点换个提示词，然后从它开始重跑下游
→ [改参数] → 节点右键「从此节点重跑下游」
```

## 快捷键

| 键 | 动作 |
|---|---|
| 滚轮 | 缩放（指针为中心） |
| 空格+拖 / 中键拖 | 平移 |
| Shift/中键+拖(空地) | 框选 |
| Cmd/Ctrl+Z | 撤销 |
| Delete/Backspace | 删除选中 |

## 已知边界

- 框选区域直接生成（inline）依赖本地快速模型，暂未开放
- 便签/Frame 参与链路时不参与「重跑」（无执行语义）
- 批量执行的历史 prompt_id 不进画布快照（只有画布手搭执行沉淀）
