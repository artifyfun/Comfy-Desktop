## 1. 结论摘要

令牌层（`theme/comfy.css` + `utils/antd-theme.js`）**已正确落地**（59a3408f），但页面层换肤**只完成了一部分**，存在三类全局性问题：

1. **令牌引用错误（S 级，修复收益最高）**：`--wb-text-1`（74 处）与 `--wb-bg`（10+ 文件）在 comfy.css **从未定义** → CSS 解析失败回退 inherit，画布/工作台多处文字色、背景色是"碰运气"状态。
2. **antd 换肤被 global.less 硬覆盖击穿（S 级）**：`Exo 2` 字体 !important（全工程无该字体源）、sky-500 focus 环、slate 半透明输入底、8px 圆角 —— 全部压过已对接令牌的 antd theme。
3. **旧视觉语言大面积残留（A 级为主）**：slate/sky/violet/emerald 色阶、渐变遮罩、玻璃拟态、发光阴影在 6 个页面 14+ 组件中仍可见，与已换肤部分同屏混排。

## 2. 全局问题（先修，一次改动覆盖全应用）

### G1 【S】令牌引用不存在变量 —— `--wb-text-1` / `--wb-bg` / `--wb-accent-bg`

comfy.css 只定义了 `--wb-text / --wb-text-2 / --wb-text-3 / --wb-bg-base`，从未定义 `--wb-text-1` 与 `--wb-bg`。

| 引用 | 分布（文件） | 影响 |
|---|---|---|
| `var(--wb-text-1)` × 74 | canvas/index.vue(53) AppNodeCard CanvasAssetsPanel CanvasSidePanel AppPickerModal；workbench index.vue InteractionApprovalCard ProgressCard ToolCallCard | 文字色回退 inherit——在暗底上大概率继承白字"侥幸可读"，一旦父链断即黑字/不可见 |
| `var(--wb-bg)` × 3+ | About Config HistoryModal 404 about apps market canvas Composer SessionSidebar | 背景透明/回退 |
| `var(--wb-accent-bg, rgba(56,189,248,.15))` | workbench/index.vue:923 | 变量未定义 → 落入 sky-400 旧色 fallback |

**修法**：一次性 grep 替换 `--wb-text-1` → `--wb-text`（次要文字按语义可换 `--wb-text-2`）；`--wb-bg` → `--wb-bg-base`；补定义 `--wb-accent-bg` 或直接内联 azure 10-15%。

### G2 【S】global.less 用 `'Exo 2'` 强制覆盖 antd 字体，但全工程无该字体源

`assets/global.less:110/163/179` 对 `.ant-btn/.ant-input/.ant-select/.ant-dropdown-menu-item/.ant-modal-title/.ant-tooltip-inner` 等写 `font-family:'Exo 2',sans-serif !important`。而：
- `main.css:1` 只 @import 了 **Inter**；
- `comfy.css --wb-font` 也是 Inter；
- **Exo 2 无任何 @font-face / CDN 引入** → antd 组件实际回退系统字体。

结果：antd 按钮/输入/下拉与页面手写 Inter 混排，观感割裂。
**修法**：删掉这三处 !important 覆盖，让 `a-config-provider :theme.fontFamily=Inter` 生效。

### G3 【S】global.less 硬编码 sky-500 / slate 半透明，压掉 antd 令牌

`assets/global.less`：
- `:143-147` `.ant-input:focus { border-color:#0ea5e9 !important; box-shadow:0 0 0 3px rgba(14,165,233,.2) !important }` —— 规范点名退役的 sky-500 + 光晕 ring；
- `:114-123` 输入/下拉背景 `rgba(15,23,42,.6)`、border `rgba(56,70,102,.6)`、`border-radius:8px !important` —— 覆盖 antd-theme.js 的 `colorBgContainer:#262729` / `borderRadius:6`；
- `:166-169` `.ant-select-item-option-selected { color:#0ea5e9 }`。

**修法**：focus 改 `var(--wb-accent)` + 2px 无 ring；输入底/描边/圆角交给 antd-theme.js 令牌（删除该段或改为引用 `--wb-*`）。

### G4 【A】tailwind tech-* 兼容别名撞色 —— purple/cyan 语义名残留但值已同化

`tailwind.config.js` 把 `tech-purple`/`tech-pink`/`tech-cyan`/`tech-green` 全部映射到 azure/danger/success 体系：
- `AppDetail.vue:25` powerLevel chip `bg-tech-purple/20 text-tech-purple` 与 :22 分类 chip `tech-blue` **并排但同色**（都是 azure），层级消失；
- `MarketAppDetail.vue:21-22` 同款撞色；
- 市场"清除筛选" `bg-tech-purple` 与"清除搜索" `bg-tech-blue` 同色。

**修法**：语义化 chip —— 分类 chip 保留 azure 描边/底，power 等级 chip 改中性 `#262729` 底 + `--wb-stroke-strong` 描边；后续随 `tech-*` 退役统一清理（PROPOSAL §2.1 已排二期）。

### G5 【A】旧 slate 色阶文字大面积蔓延（非令牌中性灰）

高频硬编码（按全库出现次数）：`#e2e8f0`(slate-200 ×72)、`#94a3b8`(slate-400 ×60)、`#64748b`(slate-500 ×29)、`#475569`(slate-600)、`text-slate-300/500/600` 遍布 apps/market/gallery/canvas/workbench。规范文字阶梯应为 `--wb-text`(白) / `--wb-text-2`(#a0a0a0) / `--wb-text-3`(#8a8a8a) 中性灰。

**修法**：`text-slate-400` → `text-[var(--wb-text-2)]`；`text-slate-300` → `text-[var(--wb-text)]` 或 -2；`text-slate-500/600`（正文/元数据）→ `--wb-text-3` 或 -2（同时解决对比度 G7）。

### G6 【A】圆角体系未收敛（6/8/10/12/14/16/24 七种并存）

规范阶梯：控件 6 / 卡片 10 / 弹窗 14。实测残留：`rounded-xl`(12) 卡片（MarketAppCard、gallery dir-card、UsageGuide）；`rounded-2xl`(16) 弹窗（canvas promptLib/角度/放大/蒙版/快捷键 dialog）；`rounded-lg`(8) 控件与图标槽遍地；canvas APP_CARD `cornerRadius:24`。

**修法**：卡片 → `var(--wb-r-card)`；弹窗 → `var(--wb-r-modal)`；控件/图标槽 → `var(--wb-r-ctrl)`。

### G7 【A】对比度不足（小字号弱灰）

实测（暗底 #171718/#262729）：
- `text-slate-600`(#475569) 11px → **≈2.2:1**（workbench 时间/token 行、canvas 分组标签）
- `text-slate-500`(#64748b) 11-12px → ≈3.2-3.8:1（gallery 计数、SessionSidebar 空态、AppSearch 提示、canvas 空态）
- `--wb-text-3`(#8a8a8a) 放 `--wb-surface-hover`(#313235) 上 ≈3.8:1（10px 级弱字要避免）

**修法**：弱字统一升 `--wb-text-2`(#a0a0a0，≈5.5:1)；`--wb-text-3` 只用于非信息性装饰。
