# Artify 工坊 · 全功能回归测试计划

> 基线：`v1.3.0-35-g1294ed1f`（2026-09-15）
> 方式：自动化无头 E2E（playwright headless chromium + electronAPI mock）为主，
> 真机人工验收点单列。每项标记【自动】或【人工】。
> 通过标准：自动化断言全绿 + 人工项无阻断缺陷。

## 一、工作台核心链路（对标 #1 harness 闭环）

| # | 用例 | 步骤 | 预期 | 方式 |
|---|------|------|------|------|
| W1 | 首轮决策 | 新会话发送文本消息 | 用户气泡上屏 → busy → PLAN 推送 → 工具执行 | 自动 |
| W2 | SSE 中断恢复 | 发消息后 kill 一次连接 | error 气泡「连接中断」+ 会话可用 | 自动 |

| W5 | 停止执行 | 运行中点停止 | 「已停止」气泡 + /agent/cancel 发出 | 自动(已有) |

## 执行顺序

1. **第一波（自动·快速）**：X1 REST 面 → T1 → A1/A2 → B1/B2 → S2（纯 HTTP/单测，~5 分钟）
2. **第二波（自动·模型）**：W1/W3 → P1/P2 → T4/T5（模型决策链，每条 1-3 分钟）
3. **第三波（自动·重链路）**：T2 → A4 → V1（真实 ComfyUI 执行，每条 1-5 分钟）
4. **第四波（人工复核）**：T7 人工固化 → 视觉项（面板样式/预览帧清晰度/布局观感）
